    4. Tell us what is good, bad or misleading

    A download contains the last calculated inputs/result plus these notes. Unsaved form or JSON edits are not represented as calculated results.

    • Move the combined COM across an edge: signed clearance should cross zero.
    • Exactly on the edge with zero required clearance: indeterminate, not pass.
    • Double both masses: same COM and clearance, double restoring moment.
    • Increase required clearance past the calculated clearance: the criterion should fail.
    • Change only COM height: horizontal gravity-only tipping clearance stays unchanged. This model does not include pushes or dynamic tipping.
    • Clear a mass/COM field: no pass. Uncheck applicability: unsupported.
